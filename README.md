# Port Killer
## A tool for anyone who wants to manage macOS ports in one place

I’m currently working on **Port Killer**, a macOS app designed to make it easier to see which ports are open on your machine. If you need to deal with a process occupying a port, you can handle it from one place without jumping between a bunch of terminal commands.

If you work in development on macOS, this problem probably feels familiar: your project won’t run because a port is already in use, you open Terminal to check which process is listening, and then you kill it step by step. Port Killer is being built to make that whole flow faster and easier to understand.

## What Port Killer can do

This project is being developed to support core features like:

- View active listening ports in real time
- Search by process name, port, PID, or user
- Kill the process that is using a port
- Pin frequently used ports as Favorites
- Keep a history of terminated processes for later review
- Enable auto refresh so the data stays up to date
- Add auto-kill rules for workflows that need automation
- Include Pro features for advanced management and monitoring
- Show key information from the menu bar for quick access

## Where the project stands now

At the moment, the project is still **in progress**, and there are several areas I’m continuing to refine, including the user experience, the accuracy of the data, and the overall workflow so it feels practical in real use.

What I want Port Killer to become is more than just an app for “killing ports.” I want it to be a tool that helps developers understand the state of their machine faster and handle port-related issues with more confidence.

## Why I’m building it

Port conflicts may seem like a small problem, but they can waste a surprising amount of time, especially when you need to debug quickly or launch something right away. Port Killer is being built to help:

- Reduce time spent on repetitive tasks
- Make port checking easier without relying only on Terminal
- Improve the development workflow
- Make system monitoring more approachable and understandable
